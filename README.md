# Codex Skills

This repository is a collection of standalone Codex skills. Each top-level
directory is one installable skill and contains its own `SKILL.md`.

## Skills

- `administrative-documents` - Chinese enterprise administrative documents,
  AI writing workbench architecture, RAG/Agent design, security governance, and
  implementation planning.
- `spark-2` - Build, debug, extend, verify, or migrate Spark 2.0 Gaussian
  Splatting apps and official examples.

## Layout

```text
administrative-documents/
  SKILL.md
  agents/
spark-2/
  SKILL.md
  agents/
  references/
  scripts/
```

To add another skill, create a new top-level directory named after the skill and
place that skill's `SKILL.md` and optional resources inside it.
